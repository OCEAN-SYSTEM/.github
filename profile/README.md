# OCEAN-SYSTEM

OCEAN-SYSTEMは、目的を絞ったWebサービス、業務ツール、開発基盤をつくり、継続して運用しています。

一つのプロダクトで一つの課題を明確に解くこと、事実と検証結果を先に示すこと、そして利用者にも運営者にも無理のない仕組みにすることを大切にしています。

## 大切にしていること

- **小さくても完全に** — 必要な機能、例外処理、アクセシビリティ、運用までを一つの成果として仕上げます。
- **証拠に基づく** — 仕様、コード、テスト、レビュー、公開後の実測を区別し、確認できた状態だけを伝えます。
- **安全とプライバシーを既定に** — 権限とデータ収集を最小限にし、秘密情報や個人情報を公開物へ持ち込みません。
- **運用できる設計** — 継続費用、保守負担、障害時の停止・復旧、変更の可逆性まで考えます。
- **プロダクトごとの責任** — デザイン、法務文書、データ、デプロイ、公開判断は、それぞれを所有するプロダクトで管理します。

## 開発と公開

基本の流れは、課題の明文化 → 小さなブランチ → Pull Request → 最新コミットの検証とレビュー → マージ → 明示的な公開判断 → 公開後の実測確認です。

ソースが完成したこと、プレビューが動くこと、本番で利用できることは同じではありません。ドメイン、認証情報、課金、法的な確約、本番変更は、コードレビューとは分けて確認します。

公開できるプロジェクトと資料は、準備が整ったものからこのプロフィール下部に表示されます。未公開の作業や内部情報は、プロフィール上では案内しません。
